# DICOM Viewer 화면과 조작 명세

현재 구현(2026-10-01)은 AppKit 단일 파일 열기·대비 목록/수치·반전·fit·확대/이동과 Metal viewport다. 파일별 generation으로 늦은 결과를 차단하고, 실제 표시 뒤의 전체 상태를 보존해 실패 시 복원한다. overlay/shutter·추정 비율 등 제한은 별도 표시한다. 최종 NSOpenPanel 사용자 경로의 회귀는 Mac 잠금으로 대기 중이다([native 표시 기록](implementation/P1-native-display.md)). 아래 검사/시리즈·cine·회전·측정·저장/PNG 등의 전체 흐름은 후속 설계다.

이 문서는 파일을 열고 영상을 탐색하며 연구 결과를 저장하는 사용자 흐름을 정의한다. 같은 영상 표시 영역을 사용하되, 프레임의 의미와 가능한 기능에 맞춰 스택 탐색, cine와 측정 도구를 제공한다.

문서 버전 0.2 · 작성·검토일 2026-09-30 · 상태 검토·보완한 설계 초안. 화면 배치, 입력 방향, 단축키와 기본값은 사용성 시험 전 제안이다.

```text
┌─────────────────────────────────────────────────────────┐
│ 열기  저장 │ W/L  확대  이동  측정 │ 1뷰  2뷰  4뷰 │ 정보 │
├───────────┬─────────────────────────────────────────────┤
│ 검사 목록 │                                             │
│           │                  영상 뷰                    │

│ 썸네일    │                                             │
├───────────┼─────────────────────────────────────────────┤
│ 가져오기  │ 프레임 이동 │ 재생과 속도 │ 표시 상태         │
│ 진행 상태 │                                             │
└───────────┴─────────────────────────────────────────────┘
                          필요할 때 정보 패널 열기
```

v0.1은 하나의 작업 창 안에서 여러 검사를 탐색하는 흐름을 기본으로 한다. 다중 독립 창과 다중 모니터 전용 배치는 후속 후보다. 정보 패널에는 DICOM 태그, 측정 목록과 연구 메모를 탭으로 제공한다. 폭이 좁아지면 부가 패널을 접고 영상 영역을 우선 유지한다.

영상 뷰에는 활성 테두리와 선택된 시리즈 이름을 표시한다. 스크롤과 단축키는 활성 뷰에만 적용한다. 인접한 뷰를 조작하기 전에 한 번 클릭하거나 시리즈를 드롭해 활성화한다.

## 파일 열기와 검사 탐색

열기 창은 파일과 폴더를 선택할 수 있게 하고, Finder에서 창으로 드래그한 입력도 같은 가져오기 흐름을 사용한다. 폴더 탐색 중에도 먼저 발견한 검사를 열 수 있다. 진행 표시에는 조사한 파일 수와 성공·실패 수를 구분하며 아직 알 수 없는 전체 수로 거짓 백분율을 만들지 않는다.

검사 목록은 날짜, 설명, modality와 식별에 필요한 정보를 제공한다. 환자 정보 숨김 설정을 적용한 경우 표시용 라벨을 사용한다. 목록 정렬은 명시적으로 바꿀 수 있고 촬영 날짜가 없는 검사는 누락 상태가 드러나게 한다.

환자 정보 숨김은 기본 목록·시리즈 라벨·영상 오버레이의 환자명과 환자 ID에 적용한다. 태그 원문, 파일 경로, 자유 메모와 영상 안의 문자는 남을 수 있음을 설정에서 설명한다. PNG 내보내기 선택은 별도로 관리한다.

시리즈 목록에는 description, modality, 프레임 수, 대표 썸네일과 제한 상태를 표시한다. 한 시리즈가 여러 display set으로 분리되면 하위 항목으로 보여준다. 공간이나 시간 의미를 확정하지 못한 목록은 단순 프레임 목록으로 표시한다.

취소는 진행 중 가져오기를 중단하고 이미 인덱싱한 결과를 유지하는 작업안이다. 취소된 범위가 모두 처리된 것처럼 표시하지 않는다. 실패 요약에서 해당 파일의 안전한 오류 설명과 다시 시도 동작을 제공한다.

## 영상 상태와 로딩

| 상태 | 표시 | 가능한 조작 |
| --- | --- | --- |
| Empty | 열기 또는 시리즈 드롭 안내 | 파일 열기 |
| Loading | 요청 프레임과 진행 표시 | 다른 프레임 선택, 취소 |
| Ready | 영상과 실제 표시 프레임 정보 | capability에 따른 도구 |
| Partial | 영상과 구체적인 제한 | 가능한 기능만 활성화 |
| Unsupported | 지원하지 않는 객체 또는 코덱 설명 | 태그 조회와 다른 시리즈 선택 |
| Failed | 해당 작업 실패와 복구 동작 | 재시도, 위치 재지정 |
| SourceMissing | 파일 위치가 사라졌다는 설명 | 원본 위치 연결 |

프레임 변경 중 이전 영상을 유지할 수 있지만, 로딩 중이라는 표시를 올리고 실제 표시 프레임 정보를 유지한다. 요청 중인 새 프레임의 라벨과 주석을 이전 영상에 붙이지 않는다. 새 프레임이 준비되면 영상·오버레이·측정을 같은 갱신에서 교체한다.

프레임 전환을 요청한 동안에는 새 측정의 생성·편집을 잠시 막고 현재 표시 프레임의 기존 주석만 보여준다. 원본 변경을 감지한 뷰는 재검증 전 측정을 중단한다. 가져오기 때문에 프레임 수나 정렬이 바뀌면 같은 FrameRef를 유지하고 새 위치 번호를 갱신한다.

## 기본 영상 조작

| 입력 | 작업안 |
| --- | --- |
| 일반 클릭 | 해당 뷰 활성화; 활성 도구에 따라 측정 점 추가 또는 주석 선택 |
| 왼쪽 드래그 | 선택한 도구 실행 |
| Option과 왼쪽 드래그 | 선택한 도구와 무관하게 임시 이동 |
| 트랙패드 pinch | 커서 또는 gesture 중심을 기준으로 확대와 축소 |
| 공간 스택의 세로 scroll | 프레임 이동 |
| 시간 시퀀스의 세로 scroll | 재생을 멈추고 프레임 이동 |
| 정지 영상의 세로 scroll | 커서 중심 확대와 축소 |
| 오른쪽 클릭 | 표시와 주석의 문맥 메뉴 |
| 더블 클릭 | fit-to-window; window/level과 주석은 유지 |

정밀 scroll 이벤트를 그대로 프레임 수로 변환하지 않고 누적량과 임계값을 사용한다. 방향과 민감도는 설정으로 조정할 수 있게 한다. 관성 scroll의 처리와 프레임 점프는 실제 마우스와 트랙패드에서 시험한다.

window/level 도구는 마우스 왼쪽 버튼을 누른 채 오른쪽으로 이동하면 폭 증가, 위쪽으로 이동하면 중심 증가를 기본 제안한다. 민감도는 데이터 범위에 맞추되 같은 영상에서는 예측 가능해야 한다. 수치 입력과 파일 VOI 목록 선택을 함께 제공한다. 컬러 프레임에서는 해당 도구를 비활성화한다. VOI LUT 선택 중 W/L 조작을 시작하면 유효 값 범위로 만든 사용자 window로 전환하고 선택 표시를 바꾼다. 기존 LUT 위에 window를 중복 적용하지 않는다.

fit, 확대, 회전과 PNG 출력은 코어의 표시 종횡비를 공통으로 적용한다. 기본 보간은 Linear이며 픽셀 확인용 Nearest를 선택할 수 있다. 픽셀 값 조회는 보간 방식에 관계없이 원본 저장 값을 사용한다.

90도 회전과 수평·수직 뒤집기는 ViewState만 바꾼다. 방향 문자와 주석도 같은 변환을 따른다. 환자 방향을 알 수 없으면 추정 L/R 문자를 표시하지 않는다.

초기화는 현재 뷰의 fit, 이동, 회전, 뒤집기, 반전, 기본 보간과 기본 VOI를 복원한다. 여기서 기본 VOI는 저장된 사용자 설정을 제외한 파일 VOI 또는 앱 자동 범위다. 프로젝트를 열 때의 저장 상태 복원과 구분한다. 저장된 주석은 유지한다.

## 프레임과 cine

공간 스택은 현재 프레임/전체 수, 가능한 경우 공간 위치, 이동 slider를 제공한다. 시간 시퀀스는 현재 프레임과 시간, 재생/정지, 처음/끝, 한 프레임 이동, 속도 배율과 loop/sweep 선택을 제공한다.

기본 시간은 [DICOM 지원 명세](03-dicom-support.md)의 timing_source를 따른다. 원본 시간 정보가 없으면 추정 속도임을 표시하고 직접 변경할 수 있게 한다. 배율 1배는 선택된 기준 시간축에 대한 배율이며 항상 실제 획득 속도를 뜻하지 않는다.

재생 구간은 유효한 파일 trim으로 시작하고 사용자가 전체 범위로 되돌릴 수 있게 한다. 프레임 번호는 원본 번호를 유지하며 현재 재생 구간을 따로 표시한다. 시간 라벨은 재생 경과 시간과 기록된 획득 기준 상대 시각을 구분한다. loop/sweep의 파일 초기값과 사용자 변경도 구분해 표시한다.

v0.1의 기본 재생은 선택된 재생 구간의 모든 프레임을 순서대로 보여주고 준비가 늦으면 기다리는 정책을 제안한다. 그 경우 실제 재생 속도가 목표보다 낮음을 표시한다. 프레임을 건너뛰며 시간축을 유지하는 방식은 선택 기능으로 추가할 수 있지만 기본 동작과 혼동하지 않게 한다.

재생 중 측정 도구를 시작하면 현재 표시 프레임에서 정지한다. 프레임마다 주석을 따로 연결하고 움직이는 영상 위에 이전 프레임의 측정을 유지하지 않는다. 시리즈 변경, 창이 비활성화되어 재생 자원이 불필요한 상황, 로딩 실패에서 재생 상태를 일관되게 정리한다.

## 비교 화면

1분할, 가로 2분할과 2×2 4분할을 기본으로 한다. 시리즈를 원하는 뷰에 드롭하거나 목록의 열기 대상을 선택한다. 레이아웃 변경 시 기존 뷰의 내용과 ViewState를 가능한 범위에서 유지한다.

v0.1은 각 뷰를 독립적으로 조작한다. 공간 연동은 후속 기능이며 같은 프레임 번호로 연동하지 않는다. 후속 위치 연동에서 조건이 맞지 않으면 연결되지 않는 이유를 표시한다.

## 측정과 연구 메모

거리 도구는 두 점, 각도는 세 점을 선택한다. ROI는 드래그로 만들고 경계 handle로 수정한다. 점을 옮기는 동안 임시 결과를 표시할 수 있지만 계산 요청이 늦게 도착하면 현재 도형 revision과 일치할 때만 반영한다.

결과에는 단위를 항상 표시한다. X-ray의 검출기·스캔 매체 기준 또는 보정 미확인 상태, 물리 간격이 없는 px 결과는 수치 옆에서 구분한다. US v0.1은 픽셀 측정과 주석을 기본으로 하고, 보정 지원 전에는 cm/mm 도구를 제공하지 않는다. spacing은 있지만 환자 방향이 없는 CT/MR은 2D mm 측정과 방향·공간 연동 불가 상태를 함께 표시한다.

회색조 ROI에는 평균, 모집단 표준편차, 최소/최대, 유효 개수와 sampled area를 표시한다. 무효 값 제외가 있으면 상세에서 확인할 수 있게 한다. 빈 ROI에 0을 정상 평균처럼 표시하지 않는다.

측정 목록에서 선택하면 해당 프레임으로 이동하고 도형을 강조한다. 주석은 이름과 메모를 가질 수 있다. 삭제와 편집에는 실행 취소를 제공한다. window/level 변경은 측정 결과를 바꾸지 않는다.

## 저장과 다시 열기

처음 저장할 때 프로젝트 이름과 위치를 선택한다. 저장 상태는 저장됨, 변경됨, 저장 중, 저장 실패로 구분한다. 제목 표시나 상태 영역에서 확인할 수 있게 하고 실패 후에도 변경됨 상태를 유지한다.

주석·메모뿐 아니라 프로젝트에 포함되는 레이아웃, 표시 프레임과 ViewState 변경도 편집 revision을 올린다. cine 중에는 매 프레임을 dirty 변경으로 기록하지 않고 정지 시의 표시 상태를 반영한다. 재생 중 저장을 요청하면 현재 표시 프레임에서 정지한 뒤 snapshot을 저장한다. 저장 중 새 편집이 발생하면 저장한 revision을 표시하되 현재 프로젝트는 변경됨으로 남긴다.

명시적 저장은 원본 검증과 프로젝트 기록이 완료됐을 때 성공으로 표시한다. 복구용 임시 저장은 별도 동작이며 사용자가 선택한 프로젝트 저장 성공으로 표현하지 않는다. 변경사항이 있는 프로젝트를 닫을 때 저장, 저장하지 않고 닫기, 취소를 제공한다.

다시 열 때 원본을 찾지 못하면 측정과 메모는 유지한 채 누락 목록을 보여준다. 위치 재지정 후 코어가 내용 일치를 확인하면 연결한다. 파일 이름이나 UID만 같고 내용이 다른 경우 자동으로 주석을 붙이지 않는다.

다른 이름으로 저장한 프로젝트도 같은 원본을 찾아야 한다. 상대 경로 재계산과 접근 권한 복구가 끝나지 않으면 그 상태를 표시한다. 이전 계산 결과는 원본 미확인 또는 재계산 필요 상태를 드러내고 현재 확인된 값처럼 표시하지 않는다.

## 내보내기

CSV는 내보낼 측정, 열과 단위를 확인한 뒤 저장한다. 표시를 위해 반올림한 문자열 대신 계산 값과 단위를 분리해 기록한다. 소수점 형식은 파일 안에서 일관되게 유지한다.

PNG는 현재 뷰의 VOI, 확대 범위, 회전과 반전을 반영하는 화면용 출력이다. 원본 DICOM이나 원본 픽셀의 무손실 연구 배열로 표현하지 않는다. 주석과 환자 정보 오버레이 포함 여부를 선택하고 미리보기로 확인한다. 기본값은 주석 포함, 환자 정보 오버레이 제외를 제안한다. 픽셀에 이미 들어간 문자까지 제거하는 기능은 아니다.

PNG의 기본 출력 크기는 활성 뷰의 영상 표시 영역에 해당하는 backing pixel 크기로 하고 저장 전에 가로×세로 픽셀 수를 표시한다. 창 테두리·도구막대·마우스 커서는 포함하지 않는다. 로딩 중에는 내보내기를 비활성화하며 cine는 정지해 확정된 표시 프레임을 사용한다. 미리보기와 저장은 같은 frame reference와 ViewState snapshot을 사용한다.

## 오류 문구의 원칙

“열 수 없음”만 표시하기보다 가능한 다음 동작을 포함한다. 예를 들어 “이 압축 형식은 현재 빌드에서 지원하지 않습니다. 태그 정보는 확인할 수 있습니다.” 또는 “원본 파일을 찾을 수 없습니다. 위치를 다시 지정하세요.”처럼 원인과 조치를 연결한다.

취소와 시리즈 전환은 일반 오류 팝업으로 알리지 않는다. 가져오기 중 파일별 실패는 모아서 제공하고, 전체 앱을 반복 알림으로 막지 않는다. 실제 결과를 확인하지 않은 상태에서 “호환됨”이나 “저장 완료”를 표시하지 않는다.

## 사용성 검증

마우스와 트랙패드, Retina 배율, 키보드 탐색, 입력 focus, 1/2/4분할, 로딩 중 도구 입력과 파일 누락 복구를 시험한다. 도구에는 접근성 이름과 선택 상태를 제공하고, 텍스트는 앱의 보통 크기에서 읽을 수 있어야 한다. 자세한 시험은 [검증 계획](06-development-and-validation.md)의 T-08, T-14부터 T-17 및 T-21을 따른다.
