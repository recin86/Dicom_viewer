# 서브에이전트 작업 배정

메인은 아래 항목을 실제 값으로 작성해 전달한다. 배정 양식은 실행 결과가 아니다.

| 항목 | 기록할 내용 |
| --- | --- |
| Task ID / 단계 / 역할 | 프로젝트 안에서 구분되는 작업 ID, P0~P5, 담당 역할 |
| 목표와 완료 동작 | 사용자가 확인할 결과 또는 기술 실험의 질문 |
| 기준 상태 | commit/build ID 또는 기준 파일·해시, 계약 revision |
| 참고 문서와 스킬 | 필요한 문서 절, 스킬 경로, UC/FR/QR·T ID |
| 수정 허용 범위 | 작성할 파일 또는 하위 경로; 공유 파일 작성권의 명시적 예외 |
| 의존성과 공유 계약 | 필요한 타입·단위·픽셀 단계·수명, 기다리는 다른 작업 |
| 합격 기준 | 독립 기대값, 성공·실패 조건, tolerance의 문서 근거 |
| 실행 환경 | 실제 사용 가능한 OS/CPU/GPU·도구와 fixture ID |
| 통합 방식 | 공유 폴더의 단일 작성자 또는 격리 작업의 기준·반환 commit |

반환 내용:

- Task ID와 완료한 범위.
- 변경 파일과 공유 계약의 영향 또는 필요한 계약 변경.
- 실행 명령·환경·fixture·기대값·실제값·pass/fail 증거.
- not-run 및 not-applicable 항목과 각각의 이유.
- 남은 문제, 외부 의존성, 다음 작업자가 알아야 할 사항.

리뷰 배정에는 수정 허용 범위를 읽기 전용으로 쓰고, 발견 사항·재현 조건·영향·위치를 반환하도록 한다.
